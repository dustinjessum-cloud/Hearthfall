## What this is

A self-contained Phaser 3 RTS/town-builder that runs from `file://` — no build
step, no bundler. Open `index.html` and it plays.

~11,000 lines across `js/*.js`, all classic scripts sharing one global scope
(no modules). Art is generated by `gen_sprites.py` (Python + PIL) into a
spritesheet that is base64-embedded into `js/content.js`.

**Four factions**, all playable from the start screen:

| Faction | Identity | Economy |
|---|---|---|
| **Human** | The baseline town-builder | 7 resources, wheat→flour→bread chain, happiness, gold, trade |
| **Undead** | Blight, corpses, bone | Carrion + bone; blight gates all building placement |
| **Tribe** | Ogres and hobgoblins | Hunts near forest, no cooking chain, plants trees |
| **Grove** | A living forest network | Structures yield by being *connected*; they mature, wither if cut, and can be fed |

**The arc:** survive 5 raids → mountain passes open → race a real AI economy
for a rich neutral zone → raze their Town Hall to win.

**The enemy town plays one of the four factions too**, drawn at world creation
and never your own, by that faction's own rules.

## The asset pipeline

Three scripts, in this order, after **any** art change:

```bash
python gen_sprites.py      # draws the sheet -> /tmp/gamebuild/
python embed_sprites.py    # base64 + regenerates FRAME in content.js
python stamp_assets.py     # md5 cache-busts the <script src> query strings
```

`embed_sprites.py` is new and exists because the old instruction was "re-embed
the base64 and rebuild FRAME by hand," which is exactly the kind of step that
goes wrong silently. It regenerates `FRAME` from `DRAWERS` order, asserts the
sprite count fits `ROWS × COLS`, and collapses the duplicated comment blocks
that earlier hand-edits stacked up. It is idempotent — safe to re-run.

**Skipping `stamp_assets.py` means the browser serves stale JS**, and you will
chase a bug that is not there.

## Non-obvious things that will bite you

- **`FRAME` in `content.js` is GENERATED** from `gen_sprites.py`'s `DRAWERS`
  order. Never hand-edit it, and never insert a sprite mid-list — that shifts
  every index after it, and a stale entry renders the *wrong sprite* rather
  than failing. Append to the END of `DRAWERS` and run `embed_sprites.py`.
- **Sprite budget is 106 of 108.** The next two are free. The third means
  bumping `ROWS` in `gen_sprites.py` **and** `rows` in `setupFrames()` in
  `main.js` **together** — they are two halves of one number, and moving one
  alone reads garbage off the end of the texture.
- **`DEPTH` in `content.js` is the draw order.** Ground 0, grove roots 1,
  buildings 2, unit markers 3, units 4, hp bars 5–6, garrison/rally 7,
  projectiles 8, targeting 9–10, ghost 9, UI 15+. Several sprites used to sit
  on implicit depth 0 and only drew above buildings because they happened to be
  *created* later — if you add a sprite, give it an explicit depth.
- **`applyFaction()` mutates shared globals and never resets**, so a page load
  hosts exactly one faction. Switching requires a reload.
- **`FACTION_DEFS` validates itself at load** against the human entry's keys, so
  a new faction missing a field names itself in the console. Add per-faction
  values there rather than writing `state.faction === 'x' ? a : b` anywhere.
- **`FACTION_DEFS.evolutionFrames`** is what a building's sprite becomes as it
  is UPGRADED. It exists because the old code special-cased the undead core and
  then fell through to human art for everyone else — an upgraded Heartwood came
  back as a stone town hall.
- **`state.buildings` holds BOTH sides.** Use `myBuildings()` / `aiBuildings()` /
  `isMine()`. Anything that re-skins a building must check ownership.
- **AI faction vs AI race are DIFFERENT vocabularies.** `aiTownFaction()` returns
  `human|swarm|tribe|grove` and drives art, names and roster. `aiTownRace()`
  returns `human|undead|troll` and is what `ENEMY_RACES` is indexed by.
- **`isRaidActive()` means "a WAVE is live"**, and tests `e.fromWave`. Skirmishes
  and bandit patrols spawn identical *kinds*, so testing kind counted one stray
  skirmisher as an active raid forever. `hasHostilesAfield()` is the broad
  question, for gates that genuinely mean it.
- **Unit behaviour comes from `UNIT_DEFS`**, not string comparisons.
- **The in-app browser preview refuses to reload `file://`.** Use the local
  server. If results look impossible, check the `?v=` stamps in `index.html`.

## Running and testing

- `.claude/launch.json` runs `python -m http.server 8123`. Serving over http is
  the only reliable way to get a real reload. **`.claude/` is untracked** — it
  also holds local settings, so it was deliberately never committed.
- Navigating with a changing query string (`index.html?cb=7`) forces a fresh
  document when the pane caches one.
- **The pane must be VISIBLE or the game loop is frozen.** If `scene` is
  undefined or `document.hidden` is true, nothing will run.
- **Read exported logs with a script, not by eye.** A 46-minute run is ~2,800
  lines of JSON; a five-line Python script that tabulates the snapshots tells
  you far more, far cheaper.
- **Two testing buttons** (purple, top bar): **Sandbox** keeps resources at cap,
  **Skip to Corridor** jumps straight to the endgame.
- **Session recorder**: red `● REC ON · n` in the top bar; **Export Log**
  downloads the run as JSON. It has caught starvation, frozen production, an
  unbuildable food building, and a 32-minute AI stall.

## Where each faction stands

**Human** — complete and the most mature. Two known traps: training a soldier
consumes the villager *instantly* but the soldier takes 60s to appear; and the
opening can stall outright (issue 1).

**Undead** — blight spreads manually (select a blight structure → Spread
Blight). Necropolis gets 1 seeding, Grave Mounds 2, capped at 2 generations.
Ritual Pit banks 20 corpses → Flesh Golem. Bone Fence (8 carrion) upgrades per
segment to a Crypt Wall (12 bone).

**Tribe** — hunting economy, Seed Grove, stake-wall art. Signature mechanic
still **open**, though the War Chief's Wildgrowth spell now does some of that
job.

**Grove** — the most developed faction after human, and the one everything
recent touched:

- Structures are placed anywhere, lie dormant as a **Seed** (one shared
  `grove_seed` sprite whatever they will become), and a root creeps to them
  from the nearest point on the network.
- **Maturation is a curve, not a metronome**: Seed→Sapling 15s,
  Sapling→Grown 50s, Grown→Ancient 180s (245s total). Output and HP scale with
  stage — yield ×0/0.5/1.0/1.35 and HP ×0.25/0.55/1.0/1.4, so an Ancient earns
  2.7× a Sapling and takes ~3× the punishment. Health carries as a *fraction*
  across stage changes.
- **Severance is a clock, not an amputation.** A cut structure bleeds 0.4% of
  max HP per second (~4 min to dead) and greys out. **Regrow Root** costs
  6 wood + 4 per tile of gap, capped by `rootMaxLen`; because repairing the
  nearest orphan extends the network, rebuilding a limb inward-out is far
  cheaper than jumping to its far end.
- **Redirect Nutrients** (Heartwood ability): feeds ONE connected structure for
  12s — heals ~5%/s and ages it 4× — while every *other* connected structure
  yields half and stops growing. 45s cooldown from when it ends. Can now target
  the Heartwood itself.
- Art: Heartwood has three ages (`grove_heart`, `_2`, `_3`), the Hollows are
  cave mouths, the Heartroot has its own transparent sprite, and the Elder
  Bough finally wears `grove_elder`.

## The enemy town

Plays one of the four factions, drawn per run, never your own. Per-faction
behaviour lives in `AI_FACTION_RULES` in `ai.js`; human is the baseline.

- **Undead** — carrion is its only resource (a `costMap` collapses wood and
  stone into food); every structure consumes a drone, never below a floor of 3;
  builds only on blight, prefers the frontier tile nearest the middle, and may
  build in the OPEN pass because its territory must be continuous.
- **Grove** — structures are inert until rooted, then pay out for being
  connected rather than staffed. Placement respects `rootMaxLen`; structures
  that fail to root at birth retry as the network grows, while ones whose root
  was CUT stay cut. **The AI does not use Redirect Nutrients or Regrow Root** —
  it has no logic to decide what to rescue, so an enemy limb just dies.
- **Tribe** — food is hunted: a camp feeds nobody unless its hunter is out on
  live forest within `HUNT.radius`. They replant, but only where the treeline
  has actually thinned, or it becomes afforestation.

`state.creep`, `state.groveRoots` and `state.groveRedirect` are each shared by
whichever side is using them, which is only safe because **a mirror match cannot
happen**. Add a mirror mode and each becomes two networks in one container.
`state.saplings` is different — it is shared TERRAIN, so it runs whenever
anyone is Tribe.

Raid waves are a **separate system** and still use the old `oppositeRace()`
logic rather than the AI's drawn faction. Left alone deliberately.

## Heroes and spells

The system was always complete; it was **empty**. `HERO_SPELLS` had one entry.
All four books are now filled — three spells each, at hero levels 1/2/3.

- XP from enemies dying within 5 tiles (own killing blows count double), max
  level 10. **Every level grants one skill point**, spendable on a new spell or
  a rank-up.
- **Power** (mana) is 60 + 12/level, regenerating 2.5 per 3s economy tick.
- `targeting: 'self'` casts instantly; `'point'` enters the shared `castMode`
  targeting used by Spread Blight and Seed Grove.
- The panel now states *why* there is no button — "needs hero level N", "fully
  ranked", "no skill points".

| Hero | J / K (always on) | Spells |
|---|---|---|
| **Minotaur** (human) | javelin, slash | War Cry, Ground Slam, Hold the Line |
| **Necromancer** (swarm) | web shot, raise broodlings | Corpse Bloom, Grave Chill, Knit Bone |
| **War Chief** (tribe) | *inherits the human javelin/slash* | Frenzy, Stampede, Wildgrowth |
| **Elder Bough** (grove) | *inherits the human javelin/slash* | Rootgrasp, Deep Root, Bloom |

Shared helpers worth knowing: `heroFuryMult()` layers War Cry / Frenzy on top
of the captain's standing damage aura (one line in `enemies.js`, and the UI
preview reads the same helper); `healBuilding()` heals and updates the hp bar;
`spellBurst()` is the shared ring effect.

**All twelve spell numbers are a first pass and untested in play.**

## Known open issues (priority order)

1. **Nothing built in the last two sessions has been played.** See the
   verification-debt section. This is the top priority.
2. **The human opening can stall completely.** `AUTO_ASSIGN_RADIUS` is 4 and
   `autoAssignIdleVillagers()` is event-driven with no periodic retry, so a
   foundation 5.8 tiles from an idle villager is never built and never retried.
   Measured: wood income zero for a whole run. Two small changes; deliberately
   deferred at the user's instruction.
3. **The Heartwood cannot grow past Ancient.** `groveMaxStage()` computes
   `min(heartwoodMaxStage: 5, stages.length-1: 3)` = 3, identical to the
   ordinary cap, so "the oldest tree is always the heart" is unimplemented.
   Needs two more stage entries.
4. **A hero's first skill point has no choice** — only the level-1 spell is
   legal, so the "two runs diverge" goal does not start until level 2. Flatten
   the `minLevel` ladder if you want a real decision on the first point.
5. **Bandit camps use different sprites fresh vs restored** — `bandit_camp` in
   `enemies.js` but a tinted `wall_gate` in `save.js`, so camps change
   appearance when you press Continue.
6. **The Grove's second Ent is unaffordable when it matters** (60 food + 40
   wood; both first affordable the moment wave 1 lands).
7. **The Grove's stone is unspendable.** Stonebark produces it; every Grove
   building costs wood only.
8. **Undead wood and stone are dead resources** — should be hidden from their HUD.
9. **Every undead building consumes a drone**, so population oscillates while
   the cap climbs.
10. **`updateUnits()` is still ~300 lines** of interleaved movement/gather/
    build/combat. Use brace-MATCHED extraction, never hardcoded line numbers.
11. **No sound at all.** Biggest perceived-quality gap.
12. Grove placeholder art remaining: **Stonebark** (`tribe_pit`), **Thornhall**
    (`tribe_warlodge`), and the Grove's archer/swordsman (`hobgoblin`/`troll`).

## How we've been working

- **Art is shown before committing** — render a comparison PNG at TRUE in-game
  size and wait for approval. Tile sprites must be shown *tiled*; a 2×2
  building is 64px, not 32. Several passes were rejected for looking fine at 8×
  and wrong at true size. **Scope worth agreeing:** new sprites get the
  approval round; tweaks to art already approved can ship.
- **Balance is argued from logs, not vibes.** There is far more built than
  validated — that is the standing tension in this project.
- **Verify in a running game, not by reading.** Most of the real bugs here were
  invisible in the source and obvious the moment something was driven: the AI's
  32-minute stall, the Grove's roots dying on reload, `Continue` throwing on any
  save with a moving enemy worker, and both seed regressions.
- **Commit and push together.** Ten commits once sat unpushed for two days while
  the GitHub Pages build served a stale game. If the branch is more than a
  commit or two ahead of `origin/main`, say so.
- **Efficiency matters.** Cost is roughly (number of tool calls) × (accumulated
  context). Batch related requests, chain shell commands, read whole functions
  once, keep tool output terse, and **start a fresh chat per batch of work** —
  that last one dominates everything else.
